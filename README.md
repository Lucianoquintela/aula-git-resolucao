# Git e GitHub — Operações Básicas

## Sobre o projeto

Este repositório contém uma atividade prática desenvolvida durante o curso **Geração Tech**, com o objetivo de aprender e praticar os fundamentos do Git e GitHub.

## Objetivos

- Conhecer o funcionamento do Git e do GitHub.
- Aprender a criar e configurar um repositório.
- Praticar os comandos básicos do Git.
- Versionar arquivos e enviar alterações para o GitHub.

## Tecnologias e ferramentas

- Git
- GitHub
- Git Bash
- Visual Studio Code

## Comandos praticados

- `git init` — inicializar um repositório.
- `git add` — adicionar arquivos à área de preparação.
- `git commit` — registrar alterações.
- `git status` — verificar o estado dos arquivos.
- `git push` — enviar alterações ao GitHub.
- `git clone` — clonar um repositório.
